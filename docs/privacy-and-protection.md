# Privacy and Protection

The public skill does not itself transmit project files to a VALARYO server. The AI agent and connected tools may process data under their own policies. Users should review provider settings and project confidentiality requirements.

If a private service is added later, disclose what data is sent, send only the minimum context, avoid secrets, define retention and deletion policies, protect logs, and document fallback behavior.

Copyright and the proprietary license set legal conditions but cannot technically prevent copying of public files. The strongest practical protection is to keep confidential prompts, algorithms, credentials, and server configuration out of the public repository. This project license is a draft and should receive qualified legal review before release.

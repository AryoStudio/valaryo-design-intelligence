# Release Checklist

- [ ] Confirm GitHub owner and repository name.
- [ ] Review all files before publishing.
- [ ] Remove credentials, tokens, private endpoints, and local paths.
- [ ] Confirm no private Core source or instructions are included.
- [ ] Validate SKILL.md frontmatter and referenced modules.
- [ ] Test discovery in the target AI agent.
- [ ] Test review, redesign, and responsive prompts.
- [ ] Verify agent does not claim unavailable tools.
- [ ] Review LICENSE with qualified counsel.
- [ ] Check Markdown links and spelling.
- [ ] Test Windows installation.
- [ ] Test other operating systems and agents before claiming support.
- [ ] Update CHANGELOG and tag only after checks.

Do not mark an item complete unless it was actually checked.

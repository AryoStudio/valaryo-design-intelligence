# Architecture and Scope

Version 0.1.0 is a public local Agent Skill: `SKILL.md` plus specialist references. It runs through the tools available to the AI agent where it is installed.

The long-term Hybrid Core plan may add a public loader, private MCP service, private API service, server-side proprietary reasoning, and local fallback. These services are NOT included, deployed, or configured in this release.

A Markdown skill is not a secure executable container. Public files can be read and copied. Keep confidential logic off the public repository and implement it on a private service if stronger technical confidentiality is required.

# Visual Quality Assurance

When browser tools are available, run the project, inspect actual routes, review mobile and desktop viewports, capture screenshots if supported, test controls and keyboard behavior, check console errors, and compare the result with the intended direction. Fix high-impact issues and inspect again.

Review hierarchy, alignment, typography, color, grid, image crop, component consistency, responsive behavior, focus states, and overflow. Check nearby pages after changing shared components.

Report exactly which routes, viewports, interactions, and tests were checked. If no browser is available, say so. Never fabricate screenshots, test passes, scores, or measurements.

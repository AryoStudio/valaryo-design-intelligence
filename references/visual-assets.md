# Visual Assets

Audit existing logos, photography, product images, illustrations, icons, and fonts before replacing anything. Select assets for relevance, authenticity, consistent art direction, composition, crop flexibility, resolution, file size, and usage rights.

Avoid unrelated stock images and fabricated product screenshots, logos, testimonials, or evidence. Keep icon families consistent. Optimize image dimensions and formats, use responsive sources where possible, lazy-load below-the-fold media, and reserve aspect ratios to reduce layout shift.

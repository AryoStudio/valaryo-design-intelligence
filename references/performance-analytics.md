# Performance & Analytics

Review image sizes, formats, font loading, CSS/JS payload, layout shift, animation cost, rendering, third-party scripts, and perceived loading. Use Core Web Vitals only when measured in a representative environment.

When analytics are provided, check time range, sample size, and event definitions. Separate correlation from causation. Recommend experiments with a clear hypothesis and metric. Without data, label recommendations as hypotheses. Never invent conversion, engagement, or A/B test results.

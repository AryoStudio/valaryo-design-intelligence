# UX, Accessibility & Ethics

Evaluate task completion, information architecture, navigation, labels, cognitive load, forms, validation, error recovery, feedback, and empty/loading/error/success states.

Aim for WCAG 2.2 AA where applicable: semantic structure, keyboard access, visible focus, sufficient contrast, form labels, accessible names, meaningful alt text, reflow, captions where relevant, and reduced motion. Automated checks do not prove full accessibility.

Avoid dark patterns: hidden costs, confirmshaming, obstructive cancellation, misleading urgency, disguised ads, and invalid consent. Make pricing, privacy choices, and consequences clear.

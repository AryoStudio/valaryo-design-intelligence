# Frontend Craftsmanship

Inspect framework, routing, styling, components, and project conventions before editing. Preserve existing functionality. Use semantic HTML, accessible names, maintainable components, consistent tokens, and predictable CSS. Avoid unnecessary dependencies and duplicate overrides.

Translate hierarchy, spacing, type, alignment, imagery, and interaction into the actual implementation. Do not claim pixel-perfect accuracy without a reference and visual comparison. Make focused changes, run relevant checks, and explain verification limits.

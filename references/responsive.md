# Responsive Design

Responsive design changes composition and behavior, not just dimensions. Use content-driven breakpoints. Starting ranges: narrow mobile 320–389 px; mobile 390–639 px; tablet 640–1023 px; laptop 1024–1439 px; desktop 1440 px and above.

Reconsider navigation, content order, grid columns, typography, image crop, touch targets, sidebars, sticky elements, and forms at each size. Test intermediate widths when needed.

Bento grids are optional. On mobile, stack or use a carefully chosen compact grid; on tablet, use columns only when content fits; on laptop, balance density; on desktop, use wider spans only when they improve hierarchy. Keep reading order logical. Prevent overflow, clipping, cramped controls, and unnecessary whitespace.
